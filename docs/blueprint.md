# **App Name**: SereneMind

## Core Features:

- Mood Logging: Allow users to log their mood using an emoji scale.
- Mood Visualization: Visualize mood trends and summaries using interactive charts and graphs.
- Journaling: Provide a guided journal prompt and space for freeform journaling.
- Sentiment Analysis: Use AI as a tool to analyze journal entries and determine potential mood triggers.
- Activity Recommendation Engine: Based on mood and journal content, suggest time-bound self-care activities.
- Positive Feedback: Present positive reinforcement messages on the mood dashboard.
- Theme Customization: Implement dark and light mode options to enhance accessibility.

## Style Guidelines:

- Primary color: Soft mint (#B1E4C5) for a calming and refreshing feel.
- Background color: Very light mint (#E8F8EF) to maintain a soothing aesthetic.
- Accent color: Soft blue (#92BCEA) to add a gentle, supportive contrast.
- Font pairing: 'Poppins' (sans-serif) for headings, 'PT Sans' (sans-serif) for body text.
- Use minimalist and soothing icons for mood states and activity types.
- Design a clean, mobile-first layout for easy navigation.
- Incorporate subtle transitions for smooth interactions.
